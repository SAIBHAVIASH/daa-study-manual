DAA LAB STUDY HUB

OFFLINE USE
1. Extract this folder or ZIP without changing its internal structure.
2. Open index.html in Chrome or Edge.
3. Keep the downloads folder next to index.html so both PDF links work.
No internet connection or installation is needed after download.

PUT IT ONLINE WITH GITHUB PAGES
1. Sign in to GitHub and create a PUBLIC repository named daa-lab-study-site.
   The repository must be public for free GitHub Pages hosting.
2. Upload index.html, README.txt, and the downloads folder to the repository root.
3. Open Settings > Pages. Under Build and deployment, select Deploy from a branch,
   choose main and /(root), then Save.
4. GitHub will show the published address. The usual form is:
   https://YOUR-USERNAME.github.io/daa-lab-study-site/
5. Use that full HTTPS address on another computer.

SIMPLE CUSTOM URL
To use a short URL such as daa-study.example.com, first obtain a domain name.
In the repository's Settings > Pages, add the custom domain, then follow GitHub's
DNS instructions from the domain provider. Enable Enforce HTTPS when it becomes
available. Do not guess DNS records; use the values GitHub shows for your domain.

COLLEGE NETWORK ACCESS
No public host or domain can guarantee that a college network will allow a site.
If the online address is blocked, ask the college IT administrator to allow the
exact HTTPS domain. For an offline backup, keep this ZIP on a USB drive, extract
it on the college computer, and open index.html in its browser. If the computer
blocks local HTML files, ask IT for an approved way to open the folder.

The page uses only local HTML, CSS, JavaScript, and the two included PDFs. It
does not load scripts, fonts, or libraries from external websites.
